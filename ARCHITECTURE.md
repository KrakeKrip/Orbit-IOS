# Orbit iOS — архитектура

## Компоненты

- apple/OrbitIOS/OrbitIOS — SwiftUI-клиент iPhone, UIKit-мосты для жестов/анимаций, уведомления, темы и ресурсы.
- apple/Orbit — Swift package OrbitCore с моделями SwiftData, операциями хранилища, валидацией, календарными проекциями и чистыми расчётами жестов.
- apple/Orbit/Tests/OrbitCoreTests — тесты ядра на macOS-хосте. macOS в platforms пакета нужен для запуска этих тестов, это не macOS-приложение.

iOS17+, Swift tools6.0. Ядро не зависит от UIKit/AppKit/HTTP. Xcode-проект использует локальный пакет по существующему относительному пути; при разделении репозитория путь не меняется.

## Сохранение

IOSStore открывает Library/Application Support/Orbit/store.sqlite внутри sandbox. CloudKit отключён. Нет аккаунтов, серверной синхронизации и внешнего пути базы через launch arguments. Успех мутации только после save; ошибка — rollback и видимое сообщение, без удаления базы.

Дата планирования и дедлайн — civil-даты. Напоминание — абсолютный момент, отображаемый в текущей зоне. Время и duration образуют полную пару, derived end не хранится. TaskDayProjector строит half-open сегменты суток; переход через полночь разбивается, нулевой сегмент не создаётся. Перенос между днями сохраняет дату/время/duration атомарно.

## Проверки и границы

swift test на macOS проверяет ядро, но не GUI. Simulator проверяет реальные экраны и собственные синтетические stores. Физический touch, haptics и VoiceOver проверяются отдельно. Не читать личные базы в QA, не менять schema без проверки upgrade. Веб-стек и macOS executable здесь отсутствуют; см. docs/REPOSITORIES.md.
