# Компактный обзор календаря при Accessibility Text

Ветка task/CALENDAR-ACCESSIBLE-HEADER, продолжение частичного D08.

В дневном и трёхдневном календаре только ограниченная верхняя область обзора и кнопка «Задачи дня» получают размер xxxLarge при Accessibility-размерах. Это сохраняет место для временной сетки. Полноразмерный отдельный список задач дня продолжает наследовать выбранный системный размер. Обычные размеры текста не затронуты. Модель, схема данных и распознавание жестов не менялись.

Проверки:
- Simulator build: BUILD SUCCEEDED, /private/tmp/orbit-accessible-header-build.log.
- git diff --check: пройден.
- Собственный iPhone 13 mini Simulator, 375pt, максимальный AX5, тёмная тема, синтетические задачи: дневная шапка компактнее, overdue и перенос в одной строке, открытие «Задачи дня» сохраняет полный AX5. Проверено GUI через Device Hub.
- Трёхдневный вариант собран, отдельно визуально в этом этапе не проверен. VoiceOver, другие темы, жесты переноса/resize не перепроверялись.

Ограничения: верхняя область по-прежнему прокручивается; частично видимая строка на границе её viewport возможна. Полная адаптация D08 и улучшение метаданных полноразмерного списка остаются в очереди.

На физический iPhone установлена и успешно запущена предшествующая сборка 4bf03b2. Изменение этого этапа проверено только в Simulator, повторно на iPhone не установлено.
