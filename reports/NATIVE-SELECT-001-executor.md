# NATIVE-SELECT-001

## Реализовано
Общее меню действий: «Выбрать» / «Настройки». Иконка — три капсулы 19×1.8 pt, промежуток 4 pt. Общий выбор строк/блоков задач, отдельный от завершения; FAB и жесты изменения интервала блокируются при выборе. Переключение контекста очищает временный выбор. Проекты-папки исключены.

Сверху только отмена и счётчик. Внизу плавающая панель с material-фоном, скруглением 28 pt, отдельной красной корзиной и коралловой кнопкой завершения. Tab bar скрывается, панель появляется переходом move+opacity 0.25 с. Нативное подтверждение удаления находится на стабильном корневом host.

Пакетные операции store разрешают все UUID до мутаций, дедуплицируют, выполняют один save с rollback. Не меняют схему. Ошибка сохраняет выбор. Пакетное завершение даёт один success feedback.

## Проверки
- Полный swift test: 116/116 PASS, включая четыре новых теста batch completion/delete, unknown UUID atomic refusal, dedup/no-op и disk reopen. Первый запуск выявил ошибку новой тестовой фикстуры (reminderAt==now); после исправления фикстуры полный прогон PASS.
- Подписанные iOS и Simulator сборки PASS; финальная правка цвета корзины проверена отдельной iOS сборкой.
- Реальный CUA GUI на своём orbit-untimed-codex: меню из двух пунктов, выбор тела/круга, счётчик 0→1→2, disabled при пустом выборе, отмена, FAB скрыт. Batch complete двух синтетических задач: одинаковый completedAt в sqlite, исходная третья задача не изменена. После перезапуска симулятора данные сохранены.
- После переноса действий вниз: скриншот CUA подтверждает нижнюю панель, отсутствие Tab Bar, верхние отмену/счётчик, выбранную строку. Открыто native delete-confirmation, destructive confirm не нажимался. Финальное удаление покрыто store-тестами, GUI удаления UNVERIFIED.
- Сервис CoreSimulator сам перезапустился в ходе проверки из-за смены версии framework; чёрный кадр 01-service-restart-black.png не является доказательством UI. Собственный симулятор восстановлен.
