# Резервное копирование — первый этап

26 октября 2026, ветка `task/BACKUP-RESTORE`.

## Поведение

Настройки → Резервная копия: экспорт через системный FileExporter, импорт через FileImporter, доступ к security-scoped URL только на время чтения. JSON v1, максимум 20 МБ; чтение ограничено maximumBytes+1 независимо от метаданных файла. Предпросмотр показывает добавляемые проекты/задачи и одинаковые записи. Подтверждение обязательно перед применением.

Выбран режим **добавления без перезаписи**: текущие данные остаются, одинаковые UUID+поля пропускаются, различающиеся версии одного UUID отклоняют весь импорт. Это восстановление на чистом устройстве или добавление отсутствующего, не откат изменённых записей к старой версии. Замена базы, настройка conflict resolution, шифрование и копирование настроек не реализованы и не обещаются UI.

Проверка структуры/полей → повторная сверка с текущей базой → материализация в отдельном in-memory store → одна запись новых моделей в рабочем context. При ошибке save rollback; схема/UUID не меняются. Напоминания обновляются после успеха по текущим разрешениям; прошедшие не должны доставляться заново.
