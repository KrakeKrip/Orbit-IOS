# TestFlight 0.2.0 (2) — 30 октября 2026

## Состав

База исходников: `29c7f98`. По сравнению с первой бета-сборкой добавлены приветствие, подзадачи, быстрый ввод из текста, повторения, виджеты, отмена действий и обратная связь. Переработан редактор задачи; проекты и цветные теги объединены на одном экране. Обновлены месячный календарь, сворачиваемые разделы, шапки и прокрутка. Исправлены зависание первого свайпа списка, стык фона при оттягивании шапки и прокрутка короткого экрана проектов.

Номер сборки приложения и расширения виджетов поднят с 1 до 2; версия остаётся 0.2.0. В Info.plist добавлен `ITSAppUsesNonExemptEncryption=false`: собственных криптографических реализаций и сторонних зависимостей в приложении нет. [Правило Apple](https://developer.apple.com/documentation/bundleresources/information-property-list/itsappusesnonexemptencryption).

Первая попытка загрузки обнаружила обязательное отсутствующее поле `CFBundleDisplayName` у нового расширения виджетов. Добавлено название Orbit, архив пересобран из исходников. Исходный архив сохранён отдельно; повторная попытка использует исправленный архив `r2`.

- Исправление прокрутки проектов подтверждено пользователем на iPhone перед подготовкой релиза. Это не полный физический прогон новой Release-сборки.
