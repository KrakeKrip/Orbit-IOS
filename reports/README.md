# Отчёты Orbit

reports/TASK-NNN-executor.md — отчёт GLM: READY_FOR_REVIEW/BLOCKED, branch, полный SHA, изменения, фактические команды с результатами и ограничения.
reports/TASK-NNN.md — независимая проверка Codex: база, все commits/diff, каждый criterion, самостоятельно запущенные проверки, обязательные замечания и результат integration.
Отчёт исполнителя не заменяет независимую приёмку. Исторические статусы относятся к моменту проверки; более поздние исправления описаны в соответствующих отчётах.
