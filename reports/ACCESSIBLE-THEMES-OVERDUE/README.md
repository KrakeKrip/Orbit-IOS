# Проверка проектов, выбора и тем при AX5

Собственный iPhone 13 mini Simulator (375pt), синтетические задачи, максимальный Accessibility Text. VoiceOver исключён по запросу пользователя.

GUI проверено:
- Проект с длинным названием открывается, строки используют всю ширину при AX5, повтор проекта в обычных строках отсутствует.
- Массовый выбор просроченной задачи: нажатие на строку меняет счётчик 0→1, кружок заполняется, действия удаления/переноса/завершения включаются. Отмена возвращает экран; данные не менялись.
- Во время проверки наступила полночь: задачи переместились в просроченные. Выбор при смене дня завершился; затем повторно проверен на стабильной дате.
- В оформлении обнаружены огромные preview и Apply. Preview теперь фиксирован на large как демонстрация палитры, Apply ограничен xxxLarge. Названия тем продолжают наследовать полный размер.
- Применены Светлая и Слоновая кость через GUI. Обе меняют поверхность настроек; календарь и проект проверены в Слоновой кости, массовый выбор — в Тёмной.
- Раскрытые просроченные в проекте после изменения показывают полное название и прошедшую дату первой длинной строки в увеличенной области.

Изменения:
- Высота прокрутки просроченных при Accessibility-размерах увеличена с 230 до максимум 420pt, обычная остаётся 230pt. Повтор подписи проекта скрыт в фильтре проекта.
- Размер стрелки переноса 20pt при прежней зоне 44×44pt; индикатор выбора темы 22pt. Последние два размера собраны, отдельный GUI проход после них не выполнен.

Проверки: финальная Simulator сборка BUILD SUCCEEDED (/private/tmp/orbit-accessible-themes-build.log), git diff --check пройден.

Ограничения: это не полная матрица размеров и тем. OLED и автоматическое переключение пары в этом этапе не перепроверялись. Длинные заголовки и названия вариантов при AX5 ещё переносятся на несколько строк. Проектный календарь и жесты не перепроверялись. На физический iPhone не устанавливалось, push не выполнялся. Core/schema не менялись.
