# NATIVE-AGENDA-PAST-BOUNDARY

Base 6272ce3. Scope: один UI-файл UpcomingAgendaScreen.

## Изменение
После явного открытия прошлого дня верхняя граница обратной прокрутки монотонно сдвигается к первому дню, чья предыдущая секция полностью ушла вверх (maxY<=0). Граница останавливается на reference today; будущие дни не запираются. Попытка прокрутить раньше границы возвращает к её секции через existing ScrollViewReader. Контент и задачи не удаляются, стабильная геометрия сохраняется.

Явная навигация календаря вновь открывает выбранный прошлый день и сбрасывает границу; старые geometry callbacks игнорируются до выравнивания новой секции. Полная группа дня, включая задачи, используется для проверки ухода; исчезновения только заголовка недостаточно.
