# Читаемость строк при Accessibility Text

Общая InboxRowView при Accessibility-размерах размещает 44pt кнопку выполнения над текстом. Название и метаданные получают всю ширину строки без уменьшения системного шрифта; разделитель выровнен по тексту. При обычном размере сохраняется горизонтальная компоновка. Изменение применяется ко всем экранам с общей строкой, а не только к списку дня.

В OrbitCalendarDayTasks при фильтре проекта скрыта повторяющаяся визуальная подпись проекта; данные и accessibility summary сохраняются.

Проверено:
- Simulator build: BUILD SUCCEEDED (/private/tmp/orbit-accessible-rows-build.log).
- git diff --check.
- Собственный Simulator iPhone 13 mini, 375pt, тёмная тема, синтетические задачи: при AX5 «Подготовить материалы» занимает две строки вместо четырёх с разрывом слов; длинный проект переносится без обрезания. Меню задачи открывается.
- Переключение на стандартный large возвращает прежнюю горизонтальную строку и плотность.

Не проверено в этом этапе: VoiceOver, массовый выбор при AX5, проектный фильтр в GUI, физический iPhone и остальные темы. Core и личная база не менялись. Полная адаптация D08 остаётся незавершённой. Установки на iPhone и push в этом этапе не было.
