# Компактная шапка трёхдневного календаря

30 октября 2026. Ветка `task/COMPACT-THREE-DAY-HEADER`.

В «Предстоящее → 3 дня» день недели и число объединены в одну строку. Маркер выбранного дня уменьшен с 44 до 32 pt (масштабируется со шрифтом); вся колонка остаётся областью нажатия высотой не менее 44 pt. При нехватке ширины подпись переносится над числом через ViewThatFits. Даты по-прежнему выровнены по трём колонкам сетки.

Когда задач без времени нет, подпись находится в левом поле строки дней; отдельная пустая строка больше не резервируется. Этот блок занимает 44 pt, как пустой блок обычного дневного календаря. На стандартном размере шрифта убрано около 60 pt высоты и в раскрытом, и в сжатом состоянии. При наличии задач без времени их карточки и прежние пределы 3/7 остаются. У стрелок периода явно задана вся область 44×44 pt для нажатия.

Общий механизм движения шапки, UIKit-прокрутка, хранение задач и жесты редактирования расписания не менялись.
