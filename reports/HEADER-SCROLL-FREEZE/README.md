# Зависание на первом свайпе списка — 30 октября 2026

Регрессия после `e5f9ff4`, сообщённая пользователем на физическом iPhone в режиме списка. Исправление на отдельной ветке `task/HEADER-SCROLL-FREEZE`.

## Воспроизведение и причина

На собственном Orbit Productivity QA (iPhone 17 / iOS 27.0, синтетические задачи) воспроизведено зависание списков «Сегодня», «Входящие» и «Предстоящее». После первого системного Scroll Down интерфейс переставал отвечать, CPU держался около 97–99%. `sample` показывал непрерывный layout/render на главном потоке.

Ограниченная временная диагностика выявила обратную связь: при неизменном нативном `contentOffset.y = -331.6667` визуальный верхний inset менялся `332 → 331.7667 → 331.93 → 331.8157…`. Каждое изменение inset считалось новым скроллом и меняло шапку, вызывая следующий layout. Простого сохранения суммарной высоты было недостаточно. Диагностический вывод удалён из итоговых исходников.

## Исправление

- Заголовок сохраняет постоянный резерв высоты. Изменения прогресса влияют на отрисовку и прозрачность, а не на размеры списка.
- Нижнее расширение области постоянно, вместо изменения padding на каждом кадре. Общий механизм применяется ко всем рабочим шапкам без отдельного варианта List.
- Observer сохраняет исходный верхний отступ после начальной компоновки. Новое положение вычисляется при изменении нативного contentOffset; изменение одного inset не обновляет состояние шапки.
- Смещение округляется до экранного пикселя. Доведение шапки использует ту же исходную систему координат.
- Данные, модели, схема и сохранённые пользовательские настройки не изменялись.

## Проверки

- Simulator build: BUILD SUCCEEDED.
- Подписанная Debug-сборка iPhone: BUILD SUCCEEDED.
- На окончательной сборке повторён ранее зависавший Scroll Down во всех трёх списках, затем обратный drag, открытие меню и переход между вкладками. Все три списка оставались отзывчивыми; CPU после проверок — 0.0% в момент измерения.
- Дополнительно проверены переключение «Сегодня» в календарь и доступность меню. Это не полный повторный проход calendar drag/resize/autoscroll.
- Персональный store не использовался. Удаления/erase/uninstall не выполнялись.
- Это целевая проверка регрессии, а не полный аудит всех тем, размеров шрифта, устройств или физического VoiceOver.

## Доставка

`devicectl` подтвердил установку на iPhoneAtl (iPhone 16e, iOS 27.2), bundle `local.orbit.ios`. Обновление выполнено поверх приложения без удаления контейнера. Автоматический запуск отклонён с причиной `Locked`; после разблокировки приложение нужно открыть вручную. Физический пользовательский свайп после обновления ещё не проверен пользователем.
