## Повторы (часть U04)

После завершения создаётся ближайший экземпляр по существующему правилу с датой строго позже дня завершения. Старые пропущенные дни не порождают цепочку просроченных экземпляров. Напоминание переносится на то же число календарных дней в текущем часовом поясе. Дедлайн не копируется. Правило описано в редакторе. Дубликаты по nextOccurrenceID по-прежнему запрещены. Схема хранения не менялась.

Проверен ежедневный повтор с задержкой в четыре дня: следующий день 26 октября вместо 22-го, время напоминания 08:50 сохраняется, повторное открытие базы сохраняет результат. Старый тест завершения закреплён на фиксированной дате.

Ограничения: месячный дрейф U13 остаётся; это не полноценная модель серии с исходным числом месяца. При очень раннем напоминании (за несколько дней) перенесённое время может уже оказаться в прошлом — существующий планировщик его не отправит. Перенос календарными днями не является новой независимой настройкой относительного смещения. DST, смена зоны и реальная доставка на iPhone в этом проходе не проверены.

## Черновик (U06)

Сравниваются все содержательные поля с исходным состоянием: название, дата, время/длительность, проект, теги, дедлайн, напоминание, подзадачи, незавершённый ввод подзадачи и повтор. Раскрытие секции само по себе не считается изменением.

Изменённую форму нельзя смахнуть; «Отмена» открывает явный диалог «Сбросить изменения / Продолжить редактирование». Неизменённая форма закрывается сразу. Это защита текущей формы, не автосохранение между перезапусками приложения.

На Simulator проверены: включение времени → попытка смахнуть не закрывает форму → Отмена показывает диалог → Продолжить возвращает время 09:00–09:30 без потери. [Снимок](discard-confirmation.png).
