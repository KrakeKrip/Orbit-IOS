# M01: короткое нажатие на задачу в List

База 3ccbc25, ветка task/LIST-TAP-FIX. Новый UX-аудит от 23 октября воспроизведён на собственном iPhone 13 mini Simulator, large, Слоновая кость, синтетические данные.

До изменения: координатный короткий tap по названию «4242» в Сегодня/Список не изменил UI. Это самостоятельное воспроизведение, не AX-активация кнопки.

Изменение: явный `.buttonStyle(.plain)` только на taskBodyMenu в общей InboxRowView. Таким образом тело строки не наследует автоматическую маршрутизацию кнопок List, а кружок выполнения остаётся независимым. Calendar TaskActionPopoverButton и его жесты не изменены. Точный внутренний порядок SwiftUI recognizers не диагностировался; причинная связь ограничена наблюдаемым эффектом локальной смены стиля.

После изменения GUI:
- тот же координатный tap по названию открывает ровно один popover;
- tap по времени и свободной правой части тела строки тоже открывает меню;
- удержание по названию сохраняет открытие меню;
- координатный tap открывает меню во Входящих и внутри проекта;
- координатный tap по завершённой задаче открывает меню с «Снова открыть»;
- bulk tap по тексту меняет счётчик 0→1, не открывает popover; Отмена завершает выбор;
- координатный tap по кружку выполняет тестовую задачу отдельно, без popover; затем задача восстановлена;
- попытки drag/scroll на тексте раскрытых просроченных не открыли меню, но смещение содержимого надёжно не подтверждено. Полную пальцевую прокрутку List нельзя считать пройденной только по этим попыткам.
