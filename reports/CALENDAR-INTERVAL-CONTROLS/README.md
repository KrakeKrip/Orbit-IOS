# D04/D05 — управление короткими интервалами

22 октября 2026. В дне и трёх днях после удержания выбранной задачи доступна закреплённая панель с названием, «Изменить время» и закрытием. Она открывает существующий точный редактор, в том числе у коротких/узких событий, где две drag-зоны пересекались бы. Предохранители высоты 44 pt/ширины 88 pt для ручек сохранены; фактическая геометрия интервала и положение точек не менялись (последнее по уточнению пользователя). Продолжительные жесты/resize/save-кандидаты не переписывались.

PreferenceKey передаёт режим выбора host-компоненту FAB: «+» скрыт из картинки, hit testing и AX, пока выбрана календарная задача. Закрытие панели, tap по фону и уход с экрана сбрасывают выделение. При смене дня также очищается выбранный UUID. Панель показывается после отпускания, не во время текущего активного жеста.

Проверки: iOS Simulator Debug BUILD SUCCEEDED, git diff --check. Собственный Orbit-Design-Unify/iPhone17/iOS27 с синтетическими задачами: удержание события 10:00–10:05 в дне → панель видна, FAB отсутствует в AX и на изображении; редактор показывает 10:00, 5 мин, конец 10:05; Cancel возвращает FAB. В трёх днях удержан тот же пятиминутный узкий блок в overlap-колонке: панель видна, FAB скрыт; закрытие панели возвращает FAB. Пользовательские базы не использовались. Интервал намеренно не менялся, сохранение редактора не нажималось.

Границы: не аттестованы все сочетания 15/30/45/60/120 мин, 1–4 перекрытия, все темы/AX/VoiceOver и физический drag/resize/autoscroll/interruption. D03 не объявляется закрытым переносом точек на углы: пользователь отменил это требование. Полная доступность плотных календарей остаётся отдельным этапом. OrbitCore не менялся, core tests не повторялись. Push не выполнялся.
