# F01 — поиск и простые фильтры

26 октября 2026. `task/TASK-SEARCH`.

Поиск по названию доступен из общего меню действий. В проекте начальная область — текущая папка с явным переключением на все задачи. Статус (все/открытые/завершённые), без даты и без проекта комбинируются через AND. Внутри проекта фильтр «Без проекта» недоступен и очищается при возврате в папку. Поиск включает просроченные и завершённые, не зависит от выбранного календарного дня. Состояние локально для sheet, после закрытия сбрасывается. Результат открывает существующий атомарный редактор. Изменений схемы и данных нет.

## Проверки

- Core: 135 тестов / 20 suites PASS, включая регистр, ё/е, диакритику, пробелы, пустой запрос, нет совпадений, сочетание фильтров, project scope и 1000 синтетических задач. Это функциональный тест, не замер производительности GUI.
- iOS Simulator Debug build PASS.
- Собственный iPhone 13 mini Simulator: открытие поиска из меню, 19 результатов при пустом запросе, «999» → нет результатов, Clear возвращает результаты, completed-фильтр → одна задача, нажатие открывает редактор с верным названием и статусом.
- Полная матрица тем, Dynamic Type, проектный переключатель и повторное открытие GUI отдельно не проходились. VoiceOver пропущен по запросу пользователя.
- Первая попытка Core-тестов через CommandLineTools не собрала SwiftData macro; повтор через DEVELOPER_DIR Xcode прошёл.
