# Предлагаемые правила интерфейса

Это целевые правила для реализации и проверки, не описание уже внедрённой системы.

| Компонент | Правило |
|---|---|
| Шапка | Один крупный заголовок в начале; компактный при прокрутке; одинаковый алгоритм во всех разделах |
| Отступы | Базовая шкала 4, 8, 12, 16, 24 pt; основной боковой отступ 16 pt |
| Нажатия | Интерактивная область не меньше 44×44 pt, даже при маленькой видимой иконке |
| Типографика | Системные масштабируемые стили; название задачи body, метаданные subheadline/caption; не фиксировать высоту многострочных строк |
| Поверхности | Один canvas, один основной surface и единый separator на тему; стекло преимущественно для навигационных элементов |
| Акцент | Коралл для действия и выбора; просрочка различима также текстом, а не только цветом |
| Формы | Постоянно доступные закрытие/сохранение; просмотр поля по возможности не изменяет данные |
| Теги | Строка — связанные задачи, многоточие — управление, цвет — дополнительный признак |
| Напоминание | Частые варианты на первом уровне, произвольная дата одним действием дальше, одно предупреждение о разрешениях |
| Анимации | Короткие переходы примерно 0.18–0.25 с как стартовая настройка; жест можно прервать; отсутствие общей пружины на всю форму |
| Уменьшение движения | Уважать системную настройку; смысл изменения сохраняется без перемещения |

Числа — исходная спецификация, а не доказательство оптимальной плотности. Проверять на коротких и длинных задачах, с клавиатурой, крупным шрифтом, в светлой и тёмной темах. Не уменьшать зоны нажатия ради компактности.
