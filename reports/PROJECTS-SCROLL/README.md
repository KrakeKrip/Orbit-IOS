# Свайп вверх в проектах — 30 октября 2026

Уточнение пользователя: на общем экране «Проекты» свайп пальцем снизу вверх не прокручивает страницу. В коротком списке нативный List не имел достаточной длины прокрутки: rubber-band возвращал его в исходное положение вместо сохранения компактной шапки.

## Изменение

- Для общего индекса проектов/тегов добавлен невидимый нижний резерв: он рассчитывается по нативным высоте viewport и высоте содержимого, чтобы короткий экран мог пройти переход шапки 80 pt. Два дополнительных пункта покрывают округление строк/пикселей.
- Для длинного списка остаётся обычный минимальный нижний резерв. При сворачивании разделов его размер пересчитывается. Отдельный редактор/выбор тегов этот механизм не включает.
- Изменения одного inset при движении шапки игнорируются: её анимация не запускает повторное изменение резерва. Добавленная область не является строкой действия и скрыта для accessibility.
- Убрано предупреждение компилятора о захвате main-actor свойства в visualEffect: в closure передаётся уже вычисленное значение CGFloat. Поведение анимации сохранено.
- Данные проектов/тегов, схема и пользовательские настройки не менялись. Экспериментальное удаление refreshable не вошло в результат: дело было в недостаточной длине короткого списка.

## Проверки

- Simulator и подписанная iPhone Debug-сборка: BUILD SUCCEEDED; warnings/errors в итоговых логах нет.
- Собственный Orbit Productivity QA / iPhone 17 / iOS 27.0, синтетические данные. Для длинного списка через интерфейс добавлены тестовые проекты 01–11; существующий синтетический A сохранён. Нижние проекты и теги доступны, обратный drag возвращает к первым строкам.
- Короткий список: «Мои проекты» свёрнуты, один тег; свайп вверх оставляет компактную шапку, обратный drag раскрывает её. Затем проверено то же движение при обоих свёрнутых разделах на окончательной сборке.
- [Окончательная короткая страница после свайпа вверх](short-list-collapsed.png).
- [Ранняя запись потягивания вниз](short-list-pull.mp4) относится к уточнению жеста до исправления, не служит его подтверждением.
- После повторных движений/изменений разделов CPU возвращается к 0.0% в момент замера, зависание предыдущего исправления не воспроизведено.
- Минимальный резерв требует iOS 18+ (как observer сворачивания). Физический жест на iPhone пользователя, полный Dynamic Type/темы/ориентации не проверены. Персональная база не использовалась, uninstall/erase не выполнялись.

## Доставка

`devicectl` подтвердил `App installed` на iPhoneAtl (iPhone 16e, iOS 27.2), bundle `local.orbit.ios`. Установка поверх приложения без удаления данных. Автоматический запуск отклонён с причиной `Locked`; после разблокировки Orbit нужно открыть вручную. Пользовательский жест на физическом устройстве остаётся отдельной проверкой.
