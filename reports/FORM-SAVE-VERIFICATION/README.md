# Напоминания, отмена и сохранность черновика

Собственный iPhone 13 mini Simulator, синтетические данные, стандартный large, Слоновая кость. Физический iPhone и личная база не использовались.

GUI-сценарии:
- Создание «4242» на 23 октября, 09:00–09:30. Включение напоминания установило 08:50, то есть за 10 минут до начала. На запрос уведомлений выбран отказ на тестовом Simulator; предупреждение «Не доставится» отображается.
- Первая попытка создания возвращала проверочную ошибку через временную подмену возврата IOSInboxModel.create. Форма осталась открыта, заголовок, дата, 09:00–09:30 и 08:50 сохранились. Повторная попытка записала задачу; календарь подтвердил значения.
- Повторное открытие напоминания показало сохранённые 08:50. Выключение в draft и Отмена сохранили прежнее напоминание; после перезапуска оно также присутствовало.
- При проверке обнаружено, что ошибка ниже видимой области длинной формы. Добавлены ScrollViewReader и прокрутка к create-error с освобождением фокуса при появлении ошибки. Повторный тест с длинным черновиком «5252» показал сообщение целиком автоматически, без ручной прокрутки. Этот черновик отменён.

Важно о границах: подмена моделировала возвращённую ошибку сохранения, а не реальный сбой SwiftData/disk. Это подтверждает обработку ошибки UI и retry, но не rollback базы при I/O failure. Временные qaFailedCreate / ORBIT_QA_FAIL_CREATE_ONCE полностью удалены, IOSInboxModel совпадает с исходным. Они не входят в коммит. Уведомления физически не доставлялись.

Сборки временного QA, проверки прокрутки и финальная обычная Simulator-сборка: BUILD SUCCEEDED. Логи /private/tmp/orbit-form-save-qa-build.log, /private/tmp/orbit-form-error-scroll-build.log, /private/tmp/orbit-form-save-final-build.log. git diff --check пройден. После проверки на Simulator установлена и запущена обычная сборка без подмены. Core-тесты на предыдущем этапе: 126/126; повторно не запускались, Core не изменялся.

Не выполнено: принудительная реальная ошибка диска, матрица всех редакторов и размеров, доставка на устройстве. VoiceOver пропущен по просьбе пользователя. На физический iPhone установка и push не выполнялись.
