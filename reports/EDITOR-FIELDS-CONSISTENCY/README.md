# Общие поля проекта, дедлайна и напоминания

TaskCreateSheet выбирает проект через Menu с тем же Picker и Binding, но общей OrbitEditorSummary в label: длинное имя переносится полностью под названием поля. TaskDeadlineFields и раскрываемая дата TaskReminderFields используют ту же компоновку. Дедлайн остаётся отдельным сроком, напоминание — отдельным абсолютным временем; логика сохранения, schema и UUID не менялись.

Проверки:
- Simulator build BUILD SUCCEEDED, /private/tmp/orbit-editor-fields-build.log.
- 126 Core-тестов в 16 suites прошли, /private/tmp/orbit-editor-core-tests.log. Это не свидетельство прохождения ошибок store в GUI.
- git diff --check пройден.
- Собственный Simulator iPhone 13 mini, 375pt, AX5, Слоновая кость, синтетические данные. Через GUI выбран проект с длинным названием, полное имя читается под «Проект»; текст черновика сохраняется при выборе проекта. Дедлайн раскрывается, назначается 23 октября. Создание успешно, список дня подтверждает дату 23 октября, выбранный проект и дедлайн. Задача без времени.
- В редакторе дедлайна выключен срок и нажата Отмена; после закрытия прежний дедлайн 23 октября сохранился.

Особенность автоматизации: кириллический ввод через typeText преобразовался текущей раскладкой; попытка setValue обновила AX-представление, но не SwiftUI binding. Не считается подтверждением ручного ввода. Для успешного сохранения использован реально введённый цифровой заголовок «23», что подтверждено после закрытия в списке. Эта задача оставлена только в собственной тестовой базе.

Не проверено: поле даты напоминания после включения в GUI, доставка уведомлений, GUI-сценарий ошибки store/восстановления черновика, полная матрица тем/размеров, физический iPhone. Обработчики ошибок не менялись. VoiceOver исключён пользователем. Push и установка на физическое устройство не выполнялись.
