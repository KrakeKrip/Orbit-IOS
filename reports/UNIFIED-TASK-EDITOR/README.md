# Единый редактор задачи — M02–M05

Ветка task/UNIFIED-TASK-EDITOR, после исправления M01.

## Изменения

Короткий тап общей строки и календарной карточки открывает один TaskCreateSheet в режиме редактирования. Он переиспользует согласованные поля создания: название, проект, дату/интервал, независимые дедлайн/напоминание. Начальные значения копируются в локальные State; редактирование не меняет store. Один Save вызывает новый OrbitTaskStore.updateTask, валидирующий весь кандидат до мутаций и сохраняющий один раз с rollback при ошибке. UUID/createdAt/schema не меняются. Сохранённый прошлый reminder допускается без изменений; новые значения проверяются. Старый интервал 1–4 минуты можно сохранить без изменения расписания, но нельзя назначить его новому времени/дате; off-grid значение присутствует в колесе без округления.

Завершение при изменённом draft подписано «Сохранить и завершить» (для завершённого — «Сохранить и снова открыть») и включает статус в ту же запись. Удаление доступно из редактора с подтверждением. Отмена и swipe без Save отбрасывают draft как в создании; отдельного предупреждения о несохранённых изменениях пока нет.

Самодельный большой popover и его анимационный/геометрический код удалены. Список использует нативный contextMenu: завершить/вернуть, выбрать, удалить. Календарь не получает contextMenu и сохраняет свой hold/drag. Название старого компонента и параметры геометрии временно сохранены для совместимости call sites; они больше не управляют презентацией.

- Первоначальный custom hold конфликтовал с release/tap; заменён нативным contextMenu. В финальной версии удержание показывает ровно три команды, «Выбрать» включает bulk с count=1, Отмена возвращает список.
- Координатный tap календарной карточки открывает тот же редактор; Cancel возвращает к той же дате и видимому диапазону. Удержание включает панель изменения времени без редактора.

## Границы

Полная матрица форм/тем/AX/трёхдневного календаря не пройдена; проект/повестка используют общий компонент, но отдельный GUI этого этапа не выполнен. Изменение даты колесом и реальная I/O ошибка общего Save отдельно в GUI не воспроизводились; атомарная валидация покрыта тестами, паттерн сохранности draft переиспользован из FORM-SAVE-VERIFICATION. Удаление через подтверждение не исполнялось. Перенос с удержанием и resize в этом этапе полностью не повторялись. VoiceOver исключён пользователем. Установка на iPhone и push не выполнялись.
