# Регрессия календарных жестов

23 октября 2026. Обычная сборка после caf614c, собственный iPhone 13 mini Simulator, стандартный large, Слоновая кость, синтетические данные. Изменений кода по результатам этого прохода нет.

GUI через CUA / Device Hub:
- Быстрое движение вниз, начатое в карточке «4242» 09:00–09:30, прокрутило сетку к полуночи. Интервал карточки не изменился, форма создания не появилась.
- Быстрое движение вверх с карточки overnight-задачи прокрутило календарь к поздним часам, без создания и изменения задачи. Большая инерция автоматизированного drag не оценивается как характеристика пальцевого жеста.
- Удержание overnight-карточки включило выбор и нижний маркер конца; появилась панель точного времени, FAB скрыт.
- Нижний маркер изменил конец с 23 октября 02:00 на 02:30 при сохранённом начале 22 октября 23:00. AX подтвердил запись. Обратным движением конец восстановлен в 02:00. X завершил выбор, FAB вернулся.
- Удержание на свободной сетке открыло создание 04:25–04:55, выбранная дата 23 октября. Отмена закрыла форму; новая задача не появилась.

Не подтверждено:
- Перенос карточки целиком удержанием, перенос из «Без времени» в сетку и обратно. Обычный drag из untimed-чипа не запустил перенос; доступный API не предоставляет надёжную единую последовательность hold-then-drag. Это не считается доказанным дефектом приложения или пройденным сценарием. Нужна ручная проверка на iPhone.
- Удлинение создаваемого интервала непрерывным удержанием, autoscroll, системное прерывание посреди жеста, верхний маркер этого прохода (прошлый отдельный GUI проход описан в CALENDAR-HANDLE-POSITION).
- Трёхдневный календарь, физические haptics и анимационные микроскачки.

Новые дефекты в подтверждённых сценариях не воспроизведены. База пользователя не использовалась. Core-тесты и build повторно не запускались: исходники не менялись, используется последняя успешная обычная сборка. Установка на физический iPhone и push не выполнялись.
