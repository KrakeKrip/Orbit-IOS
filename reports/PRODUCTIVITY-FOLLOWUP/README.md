# Productivity follow-up — 30 октября 2026

## Реализовано

- После успешного создания задачи undo сбрасывается, плашки нет. Для остальных изменений окно отмены ограничено 5 секундами; новое изменение отменяет предыдущий таймер. Удаление остаётся отменяемым в этом окне.
- Управление тегами перенесено из настроек в отдельную строку «Теги» раздела «Проекты», доступную также при отсутствии проектов. Выбор и создание тегов в задаче сохранены.
- Medium-виджет открывает выбранную задачу; прямоугольный и строковый Lock Screen — показанную первую задачу. Small и круглый продолжают открывать Сегодня: у small одна общая область нажатия при двух показанных задачах. Удалённая задача даёт явное сообщение вместо пустого редактора. Коралловый маркер вместо системного красного.
- Завершение родителя автоматически завершает все подзадачи в той же транзакции (одиночное, массовое и через редактор). Повтор создаётся с незавершёнными подзадачами; Undo восстанавливает прежнее состояние.
- Обратная связь: явное письмо разработчику с подготовленным текстом, альтернативный Share и корректно названный GitHub Issues. Письма автоматически не отправляются.
- Приветствие объясняет создание удержанием, перенос/resize и явное применение распознанного текста.
- Добавлен опциональный замер на синтетических базах 1/5/10 тысяч задач, 100 проектов. Запуск: `ORBIT_SCALE_PROBE=1 swift test` из apple/Orbit.
