# Непрерывное движение шапки — 30 октября 2026

## Причина и решение

Сравнение пользовательского ролика 16:17:37 с Todoist показало различие в непрерывности движения. Это визуальное сравнение, а не утверждение о внутренней реализации Todoist.

Старая реализация Orbit передавала каждый отсчёт через Preference → State → новые EnvironmentValues. Короткие списки и календарь дополнительно обрабатывались SwiftUI DragGesture, а доведение выполнялось Task.sleep каждые 8 мс независимо от кадров экрана. Начало/конец жеста и native scroll phases могли менять владельца движения. Заголовки затухали кусочно-линейно; стеклянная подложка меняла дерево представлений в начале перехода.

Новая реализация:
- Один наблюдаемый объект движения на рабочий экран. Значение читают только шапка и её поверхность; передача через Preference удалена.
- CADisplayLink обновляет движение по кадрам экрана и останавливается после завершения движения.
- Пассивный наблюдатель касания сохраняет координаты окна, поскольку UIScrollView может сбрасывать translation своего pan. Он не предотвращает другие recognizers и не отменяет/задерживает touches кнопок.
- Календарь и короткое содержимое получают один владелец движения с пружинным доведением, которое учитывает скорость отпускания и допускает прерывание новым касанием. Скорость ограничена для монотонного подхода к крайнему положению.
- У длинного содержимого сохраняются родная прокрутка UIKit и её границы. При остановке внутри диапазона сворачивания выполняется доведение native contentOffset.
- Затухание двух заголовков использует плавную кривую с нулевой производной на границах; дополнительное вертикальное движение большого текста уменьшено.
- Стеклянная поверхность сохраняет стабильное дерево при раскрытии/сжатии. Полностью раскрытая шапка покрыта цветом canvas.
- Начальная/изменившаяся safe-area раскладка не считается движением пальца: нулевая граница переустанавливает origin, а отрицательный native offset в покое не опускает шапку. Отпускание короткого касания также завершает прерванный возврат из отрицательного смещения.
- Отдельное модальное меню выбора тегов не управляет шапкой основного экрана через унаследованный объект движения.
