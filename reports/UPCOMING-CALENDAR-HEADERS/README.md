# Шапки «Предстоящее»: три дня и месяц

30 октября 2026. По просьбе пользователя публикация GitHub и TestFlight отложена.

До правок экран «3 дня» рассмотрен в отдельном Orbit Productivity QA Simulator. Открытие на 08:00 сразу сжимало шапку: программный scrollTo попадал в обычный обработчик native offset. Для трёхдневной шкалы подключён followsCalendarGesture, как в дневном календаре. Начальный переход к 08:00 не меняет шапку; движение пальца и доведение используют общий механизм.

В месяце отключено отдельное закрепление monthHeader. Строка месяца и стрелки уходят вместе с сеткой, а не образуют вторую стеклянную полосу под основной шапкой. Резервирование общей шапки перенесено за GeometryReader; минимальная высота учитывает фактическую оставшуюся область и нижний отступ вместо geometry.height + 80.

Проверка: Debug Simulator build успешно; CUA на синтетической базе — открытие «3 дня» на 08:00 с раскрытой шапкой, сжатие/раскрытие свайпами, возврат к 00:00; месяц — строка прокручивается с сеткой, верхняя шапка сжимается, возврат к началу и сворачивание сетки работают. git diff --check успешно. Полный проход тем/Dynamic Type/drag-resize в этой задаче не выполнялся.

По последующей просьбе пользователя Release-сборка успешно собрана и установлена поверх приложения на физический iPhone (devicectl подтвердил установку). GitHub и TestFlight не обновлялись. Визуальная проверка свайпов на телефоне остаётся за пользователем. Данные, схема и номер сборки не менялись. Существующие непричастные изменения документации сохранены.
