# Массовый выбор — D01/D02 второго аудита

22 октября 2026. Отдельное состояние выбора добавлено календарным карточкам дня и трёх дней: красный заполненный круг без галочки и контур. Оно не зависит от completed; отметка выполнения сохраняет отдельный смысл. У задач без времени в трёх днях появились круг выбора и контур. В календаре дня AX selected теперь означает выбор, а не завершённость; подсказка в режиме выбора объясняет переключение выбора. Для блоков ниже 20 pt или уже 35 pt круг скрывается ради точной геометрии; выбранность обозначена контуром и AX selected. Доступность коротких событий остаётся отдельной задачей аудита.

## Проверки

- iOS Simulator Debug: BUILD SUCCEEDED; git diff --check успешен.
- Собственный Orbit-Design-Unify, iPhone 17/iOS 27, синтетические задачи, OLED: выбор завершённой карточки дня виден, счётчик 1 и AX selected соответствуют.
- Три дня: одновременно выбраны задача без времени и завершённая timed-задача; обе имеют красные круги и контуры, счётчик 2; снятие выбора даёт 1; отмена возвращает обычный интерфейс.
- Во время GUI-проверки не выполнялись удаление, перенос или изменение completion. Модель данных и обработчики массовых операций не менялись.
- После GUI удалён дублирующий внешний контур дня; финальная правка проверена сборкой, без повторного GUI прохода.

Не пройдены полная матрица тем/ширин/Dynamic Type, физический VoiceOver и массовые операции. OrbitCore не менялся, повторный прогон его тестов для этой визуальной правки не выполнялся. Новая основная иконка входит из предыдущего коммита. На физический iPhone не устанавливалось, push не выполнялся.
