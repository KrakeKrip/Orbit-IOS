# Прокрутка и заголовки

Исправления по записи ScreenRecording_10-30-2026 01-42-36_1.MP4 и замечанию о списках, 30 октября 2026.

## Изменения

- Общая шапка следует смещению прокрутки непрерывно на первых 80 pt. Убран запуск отдельной анимации по булевому порогу.
- Крупный заголовок находится в собственной обрезаемой области; маленький — в постоянной панели. Они проявляются последовательно, без смены navigationTitle и пересоздания панели. Выбранная дата и переключатель видов не входят в анимируемый заголовок.
- Наблюдение установлено на реальные List в «Сегодня», «Входящие», «Предстоящее» и проекте. Пустым состояниям добавлена своя прокрутка. Календарь и повестка используют тот же сигнал.
- В месяце строка месяца со стрелками закрепляется во время прокрутки сетки. Содержимое не рисуется поверх шапки. Всплывающий выбор даты сохраняет обычный VStack с собственной высотой.
- В проектах и тегах убраны заполненные закруглённые плитки. Используется обычный список; пустые состояния — короткий текст без заливки. Добавление проекта/тега остаётся у заголовков, общий «+» создаёт задачу.
