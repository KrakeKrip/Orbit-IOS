## Реализация

- При раскрытой шапке используется непосредственно canvas текущей темы; стеклянный эффект не создаётся и не меняет оттенок фона.
- Матовое стекло раскрывается во второй половине сжатия, одновременно с появлением компактного заголовка. При обратном движении возвращается canvas.
- Удалены нижний градиент, 24pt растушёвка и выход поверхности вниз. Нижняя граница теперь прямая, с тонким разделителем толщиной в один физический пиксель только в компактном состоянии.
- Общий компонент применяется ко всем существующим шапкам. Геометрия viewport, жесты, данные, схемы и идентификаторы не изменялись. Режим уменьшения прозрачности сохранён.
