# Пара тем для «Как на устройстве»

22 октября 2026. В автоматическом режиме можно выбрать светлую половину (light/ivory) и тёмную (dark/oled). Сохранение вместе с режимом выполняется через «Применить тему»; выход до применения не пишет draft. Новые UserDefaults ключи orbit.ui.appearance.systemLight/systemDark независимы от данных и иконки. Без сохранённых значений — light/dark, некорректные значения нормализуются к этим же вариантам. Ручные темы остаются ручными.

OrbitTheme на корне слушает нативный colorScheme, выбирает конкретную палитру и сохраняет автоматическую нативную схему при system. Settings наследуют готовую палитру корня, чтобы открытая sheet не фиксировала старую светлую тему при смене режима.
