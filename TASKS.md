# Orbit iOS — состояние и очередь

Актуально18октября2026. Реализация — README.md; фактические проверки — reports/. Исторические NATIVE задания не являются назначением на исполнение.

## Реализовано

- Локальный Inbox, Today, проекты, создание/редактирование/завершение/удаление задач.
- Civil-планирование, интервалы, дедлайны, локальные напоминания и общий выбор звука.
- Календарь дня, перенос/resize/create, автопрокрутка, компактная область без времени.
- Предстоящее: список выбранного дня, синхронизированная повестка,3дня, месяц.
- Темы, звуковой/тактильный отклик, массовый выбор/перенос/завершение/удаление.
