# NATIVE-SELECT-001

Меню «Выбрать / Настройки» с тремя полосками и увеличенным вертикальным интервалом. Общий выбор задач в списках и календарях. Отмена и счётчик сверху; нижняя навигация скрывается, вместо неё появляется компактная панель удаления и завершения с анимацией. Удаление требует подтверждения. Состояние выбора временное, смена контекста его сбрасывает. Проекты-папки не выбираются.
