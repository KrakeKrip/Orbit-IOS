# Скриншоты Orbit iOS

Сняты **30 октября 2026** с актуальной сборки **0.2.0 (5)** на отдельном **iPhone 17 Simulator / iOS 27.0**. Тема — «Слоновая кость», статус-бар — 09:41 и 100% заряда. Все четыре оригинала имеют размер **1206 × 2622 px**.

| Файл | Экран |
| :--- | :--- |
| [today.png](today.png) | «Сегодня», список с временем, проектами и прогрессом подзадач. |
| [day.png](day.png) | Календарь дня и задача без времени. |

Это реальные экраны приложения, без дорисовки интерфейса. Перед съёмкой каждый экран осмотрен через Device Hub; оригиналы получены через `simctl screenshot`. В основном README они показаны одинакового размера в галерее 2 × 2.

Демонстрационный набор: **10 задач, 3 проекта, 3 тега и подзадачи**. Он создан штатными операциями OrbitCore и скопирован только в новый Simulator **Orbit Release Gallery**. Личная база, данные iPhone и существующие Simulator не менялись.
