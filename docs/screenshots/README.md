# Скриншоты Orbit iOS

Реальные экраны сборки после разделения репозитория, не рисованные макеты. iPhone17 Simulator/iOS27, тема Слоновая кость, статус-бар09:41/100%. Данные синтетические:12задач и3проекта созданы штатными операциями OrbitCore в отдельном временном store, затем скопированы только в собственный новый Simulator. Личные данные не использовались.

- today.png — список сегодняшнего дня.
- day.png — календарь дня, исходный screenshot без дорисовки интерфейса.

UI визуально проверен через Device Hub; файлы получены simctl screenshot и встроены в README в одинаковом размере. Переключение вкладки по координатам периодически блокировалось noWindowsAvailable; в галерею включены только фактически снятые и проверенные экраны.
