## GUI и ограничения инструмента

Прочитан навык `computer-use`, но его команда `orca skills get computer-use --json` недоступна: `zsh: command not found: orca`. Использован встроенный CUA. В Xcode 27 окно Simulator отображается приложением **Device Hub** (`com.apple.dt.Devices`), а не прежним `Simulator.app`.

В полном окне Device Hub координатные действия иногда возвращали `noWindowsAvailable`; после перехода в компактное окно координатные нажатия и drag работали. Accessibility tree использовалось для поиска существующих элементов. Часть верхних toolbar-кнопок видна на скриншоте, но не попадала в дерево CUA; для них использованы координаты. Это ограничение данного маршрута автоматизации, **не доказательство дефекта VoiceOver приложения**.

Скриншоты сняты командой `simctl io <UUID> screenshot <path>` с явно указанным собственным устройством. Оригиналы не ретушировались. `contact-sheet.png` — уменьшенный монтаж оригиналов. Даты в изображениях реальные; status bar не подменён.

Максимальный Dynamic Type включён на основном устройстве через `simctl ui ... content_size accessibility-extra-extra-extra-large`, после captures возвращён `large`. Системные часы не переводились. Проверено обновление даты после перезапуска, но не живой переход активного экрана через 00:00.

Обычный drag, начатый на календарной карточке, прокрутил сетку без изменения интервала. Удержание в «3 дня» показало выделение и ручки. Непрерывный hold+drag, автопрокрутка и resize не подтверждены: CUA-разделение удержания и следующего drag не воспроизвело перенос надёжно. Неудавшийся перенос не записан как продуктовый баг.

## Артефакты предложений

`tools/render_proposals.py` создаёт четыре статических PNG и обзор. Это геометрические макеты документации; они не запускаются в приложении. Для повторной генерации нужен Pillow и системный `/System/Library/Fonts/SFNS.ttf`. В сессии использован Python из bundled workspace dependencies. Макеты содержат схематические системные элементы, а не пиксельную копию iOS.
