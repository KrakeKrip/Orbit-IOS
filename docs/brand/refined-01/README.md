# Основной знак Orbit

Источник: пользовательский архив `refined-01.zip`, 22 октября 2026.
Основной вариант: слоновая кость, графит, коралл. Геометрия перенесена без изменений из `assets/ivory-coral-1024.png` архива в AppIcon.

Рядом сохранены исходные векторы `assets/mark.svg` и `assets/ivory-coral.svg`, а также исходный manifest цветовых вариантов. Остальные варианты из manifest доступны в пользовательском архиве; в приложение пока включён только основной.

Это замена основной иконки. Настройка выбора альтернативных иконок не реализована.
