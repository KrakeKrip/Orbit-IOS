# Orbit · refined-01

Полный исходный пакет пользовательского дизайна сохранён рядом; исходное описание предложения — [PROPOSAL.md](PROPOSAL.md). Его исторические утверждения «приложение не менялось» относятся к моменту подготовки макетов.

В приложении реализованы все 12 сочетаний: Настройки → Иконка приложения → Фон / Акцент → Применить иконку. Перебор меняет только предпросмотр; выход без применения сохраняет прежний системный значок. Фактическое состояние читается из UIApplication.alternateIconName, основной ivory-coral соответствует nil. Ошибка оставляет draft для повтора и не выдаётся за успех. Данные задач и тема независимы.

AppIcon и 11 альтернатив зарегистрированы в Xcode для Debug/Release. Стандартные PNG перенесены без изменений из исходного пакета; dark использует соответствующий night-вариант, tinted — монохромный знак на чёрном. Отдельный слой Icon Composer для clear не создавался; отображение Clear системой на устройстве ещё не аттестовано. Итог зависит от настроек домашнего экрана iOS.

Ресурсы воспроизводятся скриптом scripts/prepare_app_icons.py; проверки и ограничения — reports/REFINED-ICON-PICKER/README.md.
