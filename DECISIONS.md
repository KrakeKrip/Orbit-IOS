# Решения Orbit iOS

- Local-first: SwiftUI/SwiftData, без аккаунта, сервера и CloudKit на текущем этапе.
- iPhone — клиент этого репозитория. Web перенесён в Orbit-Web; macOS будет иметь отдельный репозиторий.
- Общий Swift-пакет и тесты остаются, поскольку это непосредственная зависимость iOS. macOS-host для swift test не означает наличие macOS-клиента.
- Четыре раздела: Сегодня, Входящие, Предстоящее, Проекты. Виды календаря: День/3дня/Месяц; отдельной Недели нет.
- Планирование, дедлайн и напоминание независимы. UUID, пользовательские данные и корректные старые интервалы сохраняются при обновлении.
- История Git не переписывается при разделении. Web переносится проверенным снимком tracked-файлов с указанием исходного SHA; macOS-снимок хранится отдельно локально до появления remote.

Полная историческая переписка решений сохранена в Git до7241700; текущие требования — PRODUCT.md и README.md.
